# Artistly - Artist Booking Platform

Artistly is a modern, full-stack web application designed to connect users with talented artists for their events. Users can easily browse, filter, and find the perfect performer, from musicians and DJs to magicians and dancers.

## 🌐 Live Demo

Check out the live version of the application: **[https://artistly-platform-ten.vercel.app/](https://artistly-platform-ten.vercel.app/)**

## ✨ Features

- **Artist Discovery:** Browse a curated list of artists with detailed profiles.
- **Advanced Filtering:** Easily filter artists by category, location, and price range to find the perfect match.
- **Dynamic Search:** Instantly search for artists by name, bio, or specialty.
- **Responsive Design:** A seamless experience across all devices, from desktops to mobile phones.
- **Dual View Modes:** Toggle between a beautiful grid view and an informative list view to browse artists your way.
- **Interactive Booking Modal:** Initiate the booking process directly from an artist's profile.
- **Loading Skeletons:** A smooth user experience with skeleton loaders while data is being fetched.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

- You can download them from [nodejs.org](https://nodejs.org/).

### Installation

1.  **Clone the repository:**

    ```sh
    git clone https://github.com/your-username/artistly-platform.git
    cd artistly-platform
    ```

2.  **Install NPM packages:**

    ```sh
    npm install
    ```

3.  **Run the development server:**

    ```sh
    npm run dev
    ```

4.  **Open your browser:**
    Navigate to [http://localhost:3000](http://localhost:3000) to see the application in action.

## Deployment :

This application is ready to be deployed on any platform that supports Next.js, such as [Vercel](https://vercel.com/), the creators of Next.js.

To deploy, connect your Git repository (GitHub, GitLab, Bitbucket) to Vercel and it will handle the build and deployment process automatically.
